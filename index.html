Checking connection…

Enter the same ADMIN_KEY you set on the server (Hostinger: api/config.php). It is saved only in this browser and is needed only on devices you use to publish.

One-time setup
  1. Hostinger: upload the api folder, open api/config.php in File Manager and replace CHANGE-ME with your own secret key.
  2. Netlify: add ADMIN_KEY in Environment variables and redeploy.
  3. Enter that key here once, then publish. Visitors on other devices do not need the key.
